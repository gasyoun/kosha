## 🧠 Dev Notes & Hypotheses (Bugs, ideas, context)

- H1943 audit result: Python 389 passed / 2 skipped (0 failing); UI 42 passed
  + build green; manifest 96 datasets (81 public · 11 restricted · 4
  intermediate), README/directory counts now match.
- **#210 closed by H1944.** The no-flag build now expands the declared graph in
  `src/kosha/build/stages.py` and runs all ten stages. Optional stages whose
  feed or local library is genuinely absent (MWinflect, vidyut) are *skipped
  with a recorded reason* in the run log, the lock file, and
  `meta.build_stage_manifest` — the distinction that was missing before is
  between "not run because unavailable" and "not run because nobody wired the
  `if`".
- **Fixture profile is the cheap reproduction.** `--profile fixture` builds the
  whole graph from `tests/fixtures/build/sources/` in ~2 s with no sibling
  repos and no network; that is what CI runs. The full-data build still needs
  the five sibling checkouts.
- **All four H1945-scope blockers are closed** (Salt-contract drift, duplicated
  API/static serialization, unsafe rendered-HTML boundary, incomplete citation
  archive/deployment contract). What remains is not code — see the queue.
- **Three defects were found by the new gates, not by inspection.**
  `/api/v1/sense` rendered both its live and its archived branch without the
  sanitizer, so the entire boundary could be walked around by asking for a
  sense instead of a lemma; Starlette's routing 404/405 escaped error
  normalization because handlers bound to FastAPI's `HTTPException` never see
  the base class the router raises; and the static-card builder's "keep the two
  in lockstep" copy of the serializer had already drifted (it never implemented
  the `raw` branch it accepted a flag for). Writing the parity/sanitizer tests
  first is what surfaced all three.
- **A Salt `id` is dictionary-scoped.** `lemma-agni` is minted by MW, PWG *and*
  Apte; C-SALT never notices because its responses are single-dictionary, but
  kosha's lemma card merges three. The key on a card is `(kosha.dict, id)`.
- **`app/` is now shims for five modules** (`render`, `cite`, `scan_resolver`,
  `evidence`, `transliterate`), which live in the installed package so the
  serializer can import them without a `sys.path` insert. Bare-name imports
  still work (D11); new code should import `kosha.<name>`.
- Rights policy is deliberately broad and risk-tolerant: uncertainty does not
  delay work or publication. Only confirmed prohibition, explicit restricted
  tier, privacy exposure, or platform policy blocks.
- Hard feature freeze remains active until H1943–H1945 merge and the
  verification freeze-exit checklist passes.
