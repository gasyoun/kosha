## 🧠 Dev Notes & Hypotheses (Bugs, ideas, context)

- H1943 audit result: Python 389 passed / 2 skipped (0 failing); UI 42 passed
  + build green; manifest 96 datasets (81 public · 11 restricted · 4
  intermediate), README/directory counts now match.
- **#210 CLOSED by H1944.** The no-flag build now runs all ten declared stages
  from a declarative registry; a stage with a missing feed aborts (or records
  an explicit skip under `--allow-missing-sources`, which a `--release` build
  then refuses), a stage that produces nothing fails, and `--stage x` refuses
  stale prerequisites. Proven by a from-zero build of the committed fixture
  pack in CI, checked stage by stage against the build lock.
- **Two defects H1944 found while proving the above, worth carrying forward:**
  (1) feed paths bound as *default arguments* in `build_db_layers` (5 loaders)
  and `build_inflections` captured their module constants at import, so
  redirecting one moved the recorded provenance without moving the read — the
  lock named a 52-line fixture while 6.9 M rows came from the real MWinflect
  tables. If a future builder takes a path, it must resolve the constant at
  call time. (2) `SecureTransport.remote_sha256` first parsed the *last* token
  of a `HASH` reply, which is the filename — the digest check degraded to a
  size check and reported success. Both now have tests that fail against the
  old behaviour.
- Remaining W0 blockers (H1945 scope): Salt-contract drift, duplicated
  API/static serialization, unsafe rendered HTML boundary, and the incomplete
  citation archive/deployment contract. History/auth is no longer a blocker —
  W0B made it default-off at the route table, not merely disabled by ruling.
- Required CI now exists (`python-ci.yml`, `ui-ci.yml`) but **branch protection
  is a human action** — see Next Steps item 2. The auto-merge gate enforces the
  same two contexts itself, so a dependency bump cannot land red even while
